# StudySprint AI 📚

**Learn a little. Improve a lot.**

StudySprint AI is a student productivity web application designed to help students build consistent study habits, organize their tasks, and improve focus through structured study sessions.

This project is built for the **Hacktoberfest Open-Source AI Challenge — Week 3: Slow and Steady**.

## What I Built

I built StudySprint AI, a responsive study dashboard that helps students manage their daily learning goals without feeling overwhelmed.

### Features

- **Study Task Manager:** Add, complete, delete, and filter study tasks.
- **Study Plan Generator:** Generate a structured study schedule based on available time and learning goals.
- **Pomodoro Focus Timer:** Use focus sessions and short or long breaks to study efficiently.
- **Progress Tracking:** View completed tasks, total tasks, focus minutes, and completion percentage.
- **Dark Mode:** Switch between light and dark themes.
- **Local Storage:** Save tasks and focus progress in the browser.
- **Responsive Design:** Use the dashboard on desktops, tablets, and mobile devices.

## How I Built It

I used the following technologies:

- **HTML5** for the application structure.
- **CSS3** for the responsive dashboard, cards, timer, and themes.
- **JavaScript** for interactive features and application logic.
- **Browser Local Storage** for saving tasks and progress.
- **Open-Source AI:** The current version uses a rule-based study-plan generator. A live open-source AI model can be integrated through an API or backend in a future version.

The goal was to create a simple and useful application without requiring a framework or build tools.

## Why Does Open Innovation Matter?

## My First User

The intended first users are students who want to organize their subjects, manage assignments, and build a consistent study routine.

StudySprint AI aims to make studying more manageable by breaking larger goals into smaller steps.

## Challenge Theme: Slow and Steady

StudySprint AI follows the idea that consistent small efforts can lead to meaningful progress.

Instead of encouraging students to study for long hours without breaks, it supports structured sessions, manageable tasks, and regular progress tracking.

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Add your study tasks and generate a study plan.
5. Start a focus session and track your progress.

No installation or API key is required for the current version.
